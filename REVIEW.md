# HackFlow · инструкция для жюри

HackFlow объединяет работу команд и организатора после отбора на студенческий хакатон. Один аккаунт работает на нескольких мероприятиях. У каждого хакатона собственные заявки, кейс, расписание, задачи, чекпоинты и итоговые решения.

## Как открыть демо

На размещённой версии Render нажмите «Попробовать демо» или откройте путь `/review`. Выберите роль и нажмите «Войти в демо». В открытом демо код и аккаунт не нужны. Если вам предоставили экземпляр с защищённым входом, введите код из инструкции к ссылке. Для одновременного просмотра двух ролей используйте разные профили браузера. В локальном демо достаточно запустить `node server.mjs --demo` и выбрать роль.

| Роль | Что посмотреть |
| --- | --- |
| Организатор | Каталог мероприятий, заявки, команды, фильтр «Требуют внимания», назначение звонка и приём решений |
| Капитан | Состав команды, доску, переписку с ментором, запрос чекпоинта и сдачу проекта |
| Участник команды | Задачи, замечания капитана, уведомления и детали звонка |
| Участник без команды | Создание состава, вступление по коду и карточку хакатона до допуска |
| Ментор | Доску назначенной команды и диалог с капитаном |
| Эксперт | Сданное решение, критерии и итоговый отзыв |

## Сценарий показа на 4 минуты

1. **Организатор.** Откройте «Мои хакатоны» и переключитесь между «Актион» и «Городские данные». Покажите, что составы и состояние работы ведутся отдельно. В «Актионе» откройте фильтр «Требуют внимания». «Орбита» уже запросила звонок.
2. **Капитан «Вектора».** Откройте «Команда». Переместите задачу Анны из «На проверке» обратно в «В работе» и оставьте замечание. В роли Анны откройте уведомление и покажите нужную карточку.
3. **Капитан и организатор.** Запросите чекпоинт, затем назначьте время из кабинета организатора. При наличии добавьте HTTPS-ссылку на звонок. В роли участника покажите дату и кнопку подключения. Открытая страница обновляет карточку в течение нескольких секунд.
4. **Сдача и заключение.** В роли капитана сдайте ссылку на решение. В роли организатора откройте карточку сдачи. В роли эксперта покажите критерии и итоговый отзыв. Если «Вектор» уже сдал проект во время предыдущего показа, используйте готовое решение «Пульса».

Для отдельной проверки регистрации откройте «Городские данные». Капитан «Вектора» может отправить состав туда одной заявкой. До одобрения кейс закрыт, после одобрения у команды появляется собственное рабочее пространство.

## Почему сценарий устроен так

- Состав собирается заранее. Капитан подаёт одну заявку за команду, организатор проверяет весь состав, а участникам не нужно дублировать регистрацию. Снимок состава сохраняется при подаче.
- Чекпоинт начинается по запросу команды. У организатора есть очередь команд, ожидающих времени или ссылки. Для самого звонка используется привычный видеосервис.
- Ментор помогает по ходу работы. Эксперт оценивает отправленное решение по критериям мероприятия. У ролей разные точки входа и права.
- Срок сдачи проверяется на сервере. Команда видит статус и время отправки, организатор открывает решение из своего кабинета.

## Технологии и границы

Сервер формирует HTML, CSS и обычный JavaScript отвечают за интерфейс, темы, фильтры и перетаскивание задач. Локальная версия и сборка для Render работают на Node.js. Обычная площадка хранит данные в JSON на диске. В открытом демо тестовые данные и изменения хранятся в памяти и сбрасываются при перезапуске. Видеозвонки и материалы открываются по внешним ссылкам. Экран регистрации не отправляет письма и не восстанавливает пароль.
